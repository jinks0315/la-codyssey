# 프롬프트 관리 프로그램

Python으로 만든 콘솔 기반 프롬프트 관리 프로그램입니다.

사용자는 프롬프트를 추가하고, 목록을 확인하고, 카테고리별로 조회하거나 검색할 수 있습니다. 또한 프롬프트 상세 정보를 확인하고 즐겨찾기를 추가하거나 해제할 수 있습니다.

## 실행 환경

* Python 3.10 이상
* VSCode
* Git / GitHub

## 실행 방법

프로젝트 폴더에서 다음 명령어를 실행합니다.

```bash
python3 main.py
```

## 주요 기능

1. 프롬프트 추가
2. 프롬프트 목록 보기
3. 카테고리별 조회
4. 프롬프트 검색
5. 프롬프트 상세 보기
6. 즐겨찾기 추가 / 해제
7. 즐겨찾기 목록 보기
8. 프로그램 종료

## 기본 프롬프트

프로그램 시작 시 기본 프롬프트 3개가 등록되어 있습니다.

* 파이썬 코드 리뷰
* 여행 일정 만들기
* 글 요약하기

각 프롬프트는 다음 데이터를 포함합니다.

* 제목
* 내용
* 카테고리
* 즐겨찾기 여부

## 카테고리

현재 기본 데이터에는 다음 카테고리가 포함되어 있습니다.

* 개발
* 여행
* 학습

새로운 프롬프트를 추가할 때 새로운 카테고리를 직접 입력할 수도 있습니다.

## 데이터 저장 방식

프롬프트 데이터는 Python의 리스트와 딕셔너리를 이용하여 관리합니다.

새로 추가한 프롬프트와 즐겨찾기 상태는 프로그램이 실행되는 동안 유지됩니다.

프로그램을 종료하면 실행 중 추가한 데이터는 초기화됩니다.

## Git 관리

기능 단위로 커밋하여 변경 이력을 관리했습니다.

프롬프트 목록 기능은 별도의 `feature/prompt-list` 브랜치에서 구현한 후 `main` 브랜치에 병합했습니다.
