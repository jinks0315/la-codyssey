# MenuMind 서비스 기획서

## 1. 서비스명

**MenuMind - AI 냉장고 요리 추천 서비스**

---

## 2. 서비스 목적

냉장고에 식재료가 남아 있어도 어떤 요리를 만들 수 있는지 바로 떠올리기 어려운 경우가 많습니다.

MenuMind는 사용자가 현재 가지고 있는 재료와 원하는 요리 조건을 입력하면 AI가 적절한 요리를 추천해주는 웹 서비스입니다.

사용자는 별도로 레시피를 검색하지 않아도 가지고 있는 재료를 활용할 수 있는 요리와 조리 방법을 간편하게 확인할 수 있습니다.

---

## 3. 주요 사용자

다음과 같은 사용자를 주요 대상으로 합니다.

- 냉장고에 남은 재료를 활용하고 싶은 사용자
- 어떤 요리를 만들어야 할지 고민하는 사용자
- 요리를 처음 시작하는 초보자
- 짧은 시간 안에 만들 수 있는 요리를 찾는 사용자
- 보유한 재료에 맞는 레시피를 빠르게 확인하고 싶은 사용자

---

## 4. 페이지 및 화면 구성

MenuMind는 하나의 웹페이지 안에서 3개의 주요 섹션으로 구성됩니다.

### 4.1 홈

서비스의 목적과 주요 기능을 소개하는 화면입니다.

주요 구성:

- MenuMind 서비스명
- 서비스 소개 문구
- AI 요리 추천 화면으로 이동하는 버튼

### 4.2 AI 요리 추천

사용자가 AI에게 요리를 추천받는 핵심 화면입니다.

주요 구성:

- 가지고 있는 재료 입력
- 요리 난이도 선택
- 조리 시간 선택
- AI 추천받기 버튼
- AI 추천 결과 출력

### 4.3 이용방법

처음 서비스를 사용하는 사용자도 쉽게 이용할 수 있도록 사용 방법을 안내합니다.

이용 순서:

1. 냉장고에 있는 재료를 입력합니다.
2. 원하는 요리 난이도와 조리 시간을 선택합니다.
3. AI 추천받기 버튼을 눌러 추천 결과를 확인합니다.

---

## 5. 핵심 기능

### 재료 입력

사용자가 현재 가지고 있는 식재료를 자유롭게 입력할 수 있습니다.

입력 예시:

```text
김치, 두부, 계란
```

### 조건 선택

사용자가 원하는 요리 조건을 선택할 수 있습니다.

요리 난이도:

- 쉬움
- 보통
- 어려움

조리 시간:

- 15분 이하
- 30분 이하
- 60분 이하

### AI 요리 추천

사용자가 입력한 재료와 선택한 조건을 AI에게 전달합니다.

AI는 입력된 조건을 분석하여 적절한 요리를 추천합니다.

### 추천 결과 표시

AI의 응답을 웹페이지에 출력합니다.

주요 결과:

- 추천 요리
- 예상 조리 시간
- 필요한 재료
- 조리 방법

---

## 6. AI 기능 설계

### AI 입력

AI에게 전달되는 주요 정보는 다음과 같습니다.

```text
보유 재료
요리 난이도
희망 조리 시간
```

입력 예시:

```text
보유 재료: 김치, 두부, 계란
요리 난이도: 쉬움
조리 시간: 15분 이하
```

### AI 처리

Python Serverless Function에서 사용자 입력을 이용하여 프롬프트를 생성합니다.

생성된 프롬프트는 Codyssey Public API의 OpenAI 호환 Chat Completions API로 전달합니다.

사용 모델:

```text
gpt-5-mini
```

### AI 출력

AI가 다음과 같은 형태의 요리 정보를 생성하도록 구성합니다.

```text
추천 요리
예상 조리 시간
필요한 재료
조리 방법
```

출력 예시:

```text
추천 요리: 김치두부전

예상 조리 시간: 약 10~15분

필요한 재료:
김치, 두부, 계란 등

조리 방법:
1. 두부의 물기를 제거합니다.
2. 김치와 두부를 준비합니다.
3. 재료를 섞어 반죽을 만듭니다.
4. 팬에서 앞뒤로 익힙니다.
```

## 7. AI 요청 흐름

전체 요청 과정은 다음과 같습니다.

```text
사용자
  ↓
재료 및 조건 입력
  ↓
JavaScript
  ↓
fetch() POST 요청
  ↓
/api/recommend
  ↓
Python Serverless Function
  ↓
Codyssey Public API
  ↓
GPT-5 Mini
  ↓
AI 추천 결과 생성
  ↓
JSON 응답
  ↓
JavaScript
  ↓
사용자 화면에 결과 출력
```

## 8. 실패 및 예외 처리

### 재료를 입력하지 않은 경우

사용자가 아무런 재료도 입력하지 않고 AI 추천받기 버튼을 누르면 API를 호출하지 않고 다음 안내 메시지를 표시합니다.

```text
가지고 있는 재료를 입력해주세요.
```

### AI 요청 중

AI 응답을 기다리는 동안 다음 메시지를 표시합니다.

```text
AI가 요리를 찾고 있습니다...
```

중복 요청을 방지하기 위해 추천 버튼을 일시적으로 비활성화합니다.

### API 또는 서버 오류

AI API 호출 또는 서버 처리 중 문제가 발생하면 다음과 같은 오류 안내를 표시합니다.

```text
요리를 추천하지 못했습니다.
잠시 후 다시 시도해주세요.
```

이를 통해 서버 내부 오류 내용을 사용자에게 직접 노출하지 않습니다.

## 9. 반응형 웹

PC뿐만 아니라 모바일 환경에서도 사용할 수 있도록 CSS Media Query를 적용했습니다.

화면의 너비가 작아지면:

- 내비게이션 크기 조정
- 제목 및 글자 크기 조정
- 이용방법 카드 3열 구조를 1열 구조로 변경

등의 방식으로 모바일 화면에 맞게 레이아웃이 변경됩니다.

Codyssey Public API

## 11. API 키 보안

API 키가 브라우저의 JavaScript 코드에 노출되지 않도록 프론트엔드에서 AI API를 직접 호출하지 않습니다.

브라우저에서는 `/api/recommend`만 호출하며 실제 AI API 호출은 Python 서버에서 처리합니다.

API 키는 코드에 작성하지 않고 Vercel의 Environment Variables에 다음 이름으로 저장합니다.

```text
OPENAI_API_KEY
```

실제 API 키 값은 GitHub 저장소에 업로드하지 않습니다.

## 12. 기대 효과

MenuMind를 통해 사용자는 가지고 있는 재료를 활용할 수 있는 요리를 빠르게 확인할 수 있습니다.

또한 AI를 활용하여 사용자가 입력한 재료와 난이도, 조리 시간에 따라 매번 다른 조건의 요리 추천을 받을 수 있습니다.

이를 통해 단순히 정해진 레시피를 보여주는 웹페이지가 아니라 사용자 입력에 따라 결과가 생성되는 AI 기반 웹 서비스를 구현하는 것을 목표로 합니다.
